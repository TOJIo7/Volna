# Волна — музыкальное приложение для Android

Тёмное приложение в стиле Spotify. Музыка берётся из открытого каталога Audius, где артисты сами публикуют свои треки.

## Что умеет

- Поиск по всем популярным песням мира (Deezer): отрывок 30 секунд и кнопка «Слушать полностью» в YouTube или Spotify
- «Мои файлы»: добавляй свои MP3 с телефона — играют целиком и без интернета
- Полные треки независимых артистов из Audius, поиск исполнителей
- Главная: «Для тебя» (подборка по жанрам, которые ты слушаешь), тренды недели, жанры, недавно прослушанное
- Плейлисты: создать, переименовать, удалить, добавить и убрать треки
- Любимые треки и история прослушиваний
- Скачивание треков и целых плейлистов — играют без интернета
- Офлайн-режим: приложение само видит, что интернета нет, и показывает скачанное
- Полноэкранный плеер: перемотка, перемешивание, повтор (всё / один трек), очередь
- «Играть следующим» и «Добавить в очередь»
- Автовоспроизведение похожей музыки, когда очередь закончилась
- Таймер сна (5–90 минут или до конца трека, с плавным затуханием)
- Эквалайзер на 5 полос и 8 пресетов
- Музыка играет при выключенном экране, управление из шторки, на экране блокировки и кнопками наушников

## Как получить APK (без компьютера, с телефона)

1. Зарегистрируйся на github.com (бесплатно).
2. Создай новый репозиторий (кнопка «New»), например `volna`.
3. Загрузи в него все файлы из этой папки, сохранив структуру папок.
   С телефона проще всего так: пришли Claude название репозитория — он загрузит всё сам.
4. Открой вкладку **Actions** — сборка «Собрать APK» запустится сама и займёт 3–6 минут.
5. Когда появится зелёная галочка, открой вкладку **Releases** → «Волна — последняя сборка» → скачай `Volna.apk`.
6. Открой файл на телефоне. Если Android спросит — разреши установку из этого источника.

При каждом новом изменении в репозитории APK пересобирается сам. Новая версия ставится поверх старой, плейлисты и скачанная музыка сохраняются.

## Как собрать на компьютере

Открой папку в Android Studio и нажми Run, или выполни `./gradlew assembleRelease`.
Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

## Устройство проекта

- `app/src/main/assets/www/index.html` — весь интерфейс и логика плеера
- `MainActivity.kt` — окно приложения, кнопка «Назад», проверка интернета
- `NetProxy.kt` — запросы к каталогу Audius (нужно для эквалайзера и перемотки)
- `Downloader.kt`, `Storage.kt` — скачивание и хранение музыки в памяти приложения
- `PlaybackService.kt` — фоновое воспроизведение и уведомление с кнопками
- `app/volna.keystore` — ключ подписи (пароль `volna123`), чтобы обновления ставились поверх

## Если каталог перестанет отвечать

В настройках приложения можно вставить ключ Audius API (бесплатно на audius.co, раздел для разработчиков).
